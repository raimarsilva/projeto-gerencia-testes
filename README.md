# Gestor de Contratos
Sistema web para gestão de contratos de trabalho temporários de docentes da UFRN.

## Tecnologias
- Java
- Spring Boot / Gradle
- Spring Web
- Spring Data JPA
- Springdoc OpenAPI UI
- PostgreSQL
- Docker
- Junit
- JaCoCo (EclEmma)
- Thymeleaf
- JSF

### Execução com Docker
Com o docker instalado na máquina, acesse a pasta
raiz do projeto e execute os comandos abaixo para
rodar o projeto.

    $ docker-compose build
    $ docker-compose up
